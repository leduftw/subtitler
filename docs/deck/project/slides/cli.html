Command line

The command line follows the playbook’s rules

Four words are commands

help, version, update and upgrade count only as the first word, so ./help still reaches a file called help.

Everything else is a flag

--list-languages and --translation-guide print and exit; --emit-worksheet and --apply-worksheet translate.

Two kinds of failure

A command-line mistake exits 2 with the usage line; a failure while running, like a missing ffmpeg, exits 1.

A bare subtitler explains itself

With no arguments it prints the help and the one thing it needs: a video or audio file. Colors appear only in a terminal.
