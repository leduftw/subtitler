The worksheet keeps every line’s number

# subtitler worksheet v1
# source: es    target: en
# (how to translate this file)

[?] 00:00:01,000
1| y gracias por venir a esta reunión que,
2| como ya saben, hemos aplazado
3| tres veces.

[?] 00:00:04,200
4| - ¿Tres veces?

[?] because an .srt carries no speaker ids: turns split at each “- ” instead.

Whole sentences

Lines are grouped into speaker turns, so the translator reads complete sentences, not fragments.

Numbers carry the timing

--apply-worksheet refuses a missing, repeated or unknown number rather than shift every later subtitle.

Turn marks survive

A leading “- ” stays in the translation, so the new file still marks each change of speaker.
