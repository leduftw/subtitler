Providers

A registry keeps the pipeline provider-agnostic

Each provider module

SPEC

A ProviderSpec: label, default model and audio format, upload cap, price a minute, languages, whether it can diarize, whether it’s internal

build(config)

A TranscriptionProvider, whose validate() checks the keys and whose transcribe() returns a list[Cue]

providers/__init__.py

NAMES

Every spec not marked internal: the --provider choices scribe, azure-fast and azure-hybrid

spec(name)

Any provider’s metadata, azure-mai’s included: cli.py takes the --azure-model default from it

build(config)

The provider that config.provider names, ready to run

Adding a provider is a module under providers/ plus one entry in the registry. azure-hybrid imports azure-mai’s request builder and 43-language list directly.
