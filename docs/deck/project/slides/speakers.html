The cue model

A new speaker always starts a new cue

Without speakers

Sorry I you don’t need to apologize.

Two voices land in one cue, and the interruption is lost.

With speakers

2
00:00:07,120 --> 00:00:08,340
- Sorry, I

3
00:00:08,340 --> 00:00:09,900
- You don't need to apologize.

Each turn gets its own cue, marked with the dialogue dash.

render_srt marks each new turn with “- ” only when the file holds two or more speakers, so a single voice renders clean.

On by default for scribe, azure-fast and azure-hybrid. --no-diarize turns it off, and --max-speakers sets the ceiling, 8 by default.
