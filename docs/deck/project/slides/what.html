What it does

A file goes in, subtitles come out

Transcribe

Pulls one audio track out of a video or audio file with ffmpeg, sends only that audio to a speech model, and writes an .srt.

Tell speakers apart

Every provider you can pick separates speakers by default, and a new speaker always starts a new subtitle.

Translate

Turns an existing .srt into another language through a numbered worksheet, so every timestamp stays where it was.

Python’s standard library only: nothing else to install

Only the extracted audio ever leaves the machine

No UI, no database, no background service
