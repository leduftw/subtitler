The pipeline

Every check runs before the paid API call

1

The input exists and is a file, or the run exits 2

2

ffmpeg and ffprobe are on PATH

3

An existing .srt stops the run, unless --force

4

The registry builds the chosen provider

5

ffprobe’s duration gives the cost estimate

6

The provider’s keys are set (not checked on --dry-run)

7

ffmpeg extracts the audio into a temporary folder

8

Audio over the provider’s upload cap is refused

9

--dry-run stops here, before any API call

10

Transcribe, render the cues and write the .srt
