The pipeline

One run is a straight line from file to .srt

Media file

Any video or audio file that ffmpeg can read

ffmpeg

By default: first audio track, mono 16 kHz mp3 at 48 kbit/s

Provider

One upload of that audio to a speech API; azure-hybrid makes two

Cues

A list[Cue]: start, end, text and speaker

.srt file

render_srt numbers the cues, wraps the lines and marks each turn

Before extracting, ffprobe tries to read the duration; when available, subtitler prints the provider’s estimated cost.

--dry-run stops once the audio is extracted: no API call, and no .srt.
