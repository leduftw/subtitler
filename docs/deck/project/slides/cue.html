The cue model

Every provider returns the same four fields

@dataclass(frozen=True, slots=True)
class Cue:
    start_ms: int
    end_ms: int
    text: str
    speaker: int | None = None

Cues, never SRT text

transcribe(audio, timeout) returns a list[Cue] in time order, for every provider.

Rendered in one place

srt.py numbers, wraps and marks speakers, so no provider can do it differently.

Words are cues too

A provider with word timings makes one Cue per word and hands them to group_words_into_cues.

A speaker is a number

The provider’s diarization id, or None when it didn’t tell speakers apart.
